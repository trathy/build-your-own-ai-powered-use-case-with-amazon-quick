Quick Apps turn a data workflow into an interactive web application anyone can use.

## Step 1: Build the app

Navigate to **Apps** in Amazon Quick:

```text
Build a Quick App called "{Your Focus Area} Monitor" using the data
in the "{Space name}" Space.

It should:
- Show a scorecard ranking {entities} by {central metric} with color
  indicators (green/yellow/red based on targets)
- When an entity is selected, show its trend and key contributing factors
- Include a "Risk Alerts" section flagging anything below target
- Include a plain-language question box for ad hoc queries

Use a clean, professional layout. The scorecard should be the focal
point. Keep it simple enough that anyone can use it without training.
```

## Step 2: Test the app

- [ ] Scorecard shows all entities with correct values and colors
- [ ] Selecting an entity shows the right detail
- [ ] Risk alerts flag the correct items
- [ ] Question box returns grounded answers

## Step 3: Iterate

Describe fixes conversationally: "Move the alerts to the top" or "Add a date filter." Quick Apps are refined through conversation.

## The platform close

After building the app, connect all seven capabilities:

| Capability | What it proves |
|------------|---------------|
| **Space** | Upload data once, anyone can query it |
| **Chat Agents** | Same data, different perspectives per role |
| **Research** | Deep analysis with citations on demand |
| **Flow** | Automated workflows on schedule |
| **Dashboard** | Visual analytics with natural language Q&A |
| **Topic** | Governed metrics with data lineage |
| **Quick App** | Interactive tool anyone can use |

> "One dataset. Seven ways to consume it. Governed from the center."
